Getting Started

Uno Mega Menu

A short walkthrough of the builder, from install to a published menu.

1. Install and open

Install Uno Mega Menu from the Shopify App Store. Open it from Apps in your Shopify admin.

2. Start a menu

Pick a ready-made template or start from your existing navigation. Drag items to reorder them.

3. Build a mega panel

Click any menu item to open its editor. Turn it into a mega panel or a set of tabs. Add products, collections, images or badges straight inside it.

4. Style it

Choose a built-in style or customize colors, fonts and spacing to match your brand. Save your own style to reuse on other menus.

5. Preview and save

Switch between desktop and phone preview before saving. Your storefront updates as soon as you save.

What the paid plans add

Pro adds a broken-link checker for your whole menu. Plus adds manual translations for every menu item. Studio adds one-click AI translation into many languages.
