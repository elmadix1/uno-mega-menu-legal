FAQ

Les bonnes questions

Pouvez-vous construire le menu à ma place ?

Oui. Avec le service clé en main, votre menu est construit directement dans votre boutique puis mis en ligne, pour un prix fixe dès 49 $. Vous envoyez un court brief, vous validez un aperçu et vous gardez ensuite la main sur tout. Voir les formules et les prix.

L'app va-t-elle ralentir ma boutique ?

Non. Le menu arrive dans la page elle-même. Il s'affiche donc en même temps que tout le reste : pas de chargement visible, pas d'apparition tardive, pas de saut de mise en page. L'app pèse moins de 30 Ko de CSS et de JavaScript réunis, ne charge rien depuis des serveurs externes et n'envoie aucune requête tant que le visiteur n'interagit pas. Vos liens de navigation sont en HTML simple, lisibles par les moteurs de recherche.

Est-ce compatible avec mon thème ?

Oui. Uno est un bloc d'app que vous ajoutez à votre en-tête depuis l'éditeur de thème. Il fonctionne avec tous les thèmes Online Store 2.0. Sur les thèmes plus anciens, le bloc n'est pas ajouté automatiquement : vous l'ajoutez vous-même depuis le sélecteur de blocs. L'app vous guide dans les deux cas.

Ma boutique sera-t-elle plus lente ?

Non. Le menu est rendu sur les serveurs de Shopify avec votre page, dans la même requête. Aucun serveur d'app externe sur le trajet, aucun framework JavaScript, aucun flash de menu sans style pendant un chargement. Les ressources se limitent à une petite feuille de style et un petit script.

Que se passe-t-il si mes prix ou mes stocks changent ?

Le menu suit, dès la page vue suivante. Les cartes produit lisent les données en direct de votre boutique : prix actuel, ancien prix barré en promotion, fourchettes de prix entre variantes, produits épuisés et conversion de devise par marché. Rien n'est copié, donc rien ne se périme.

Je vois deux menus. Est-ce normal ?

Oui. Juste après l'activation, le menu d'origine de votre thème est toujours là. Vous le masquez avec un petit extrait de CSS fourni par l'app, avec le chemin exact de l'endroit où le coller. Comptez environ une minute.

Que se passe-t-il si je désinstalle l'app ?

Le bloc de menu disparaît avec l'app. Uno n'injecte aucun code dans les fichiers de votre thème : il n'y a rien à nettoyer. Le menu d'origine de votre thème est toujours à sa place.

Puis-je essayer un plan payant d'abord ?

Chaque plan payant inclut un essai gratuit de 14 jours et le plan Free n'a aucune limite de durée. Vous pouvez aussi tout créer et tout tester sur une boutique de développement avant de toucher à votre thème en ligne.

Que mesurent les statistiques du menu ?

Les clics, les ajouts au panier et les ventes, comptés pour chaque élément du menu : entrées, onglets, liens, cartes produit. Quand une commande contient un article ajouté au panier depuis le menu, la vente et son montant (remises déduites) sont attribués à cet élément. Aucune donnée personnelle n'est stockée, seulement des compteurs anonymes. Les chiffres de plus de 90 jours sont effacés. Le comptage tourne sur tous les plans dès le premier jour : quand vous passez à Studio, votre historique est déjà là.
